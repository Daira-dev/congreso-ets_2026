Manual Técnico de Configuración del Servidor SMTP (Nodemailer)

Este documento detalla el procedimiento técnico para configurar el envío automático de credenciales digitales y confirmaciones de registro del Congreso ETS 2026 utilizando una cuenta oficial de Google Workspace o Gmail convencional.

El sistema backend está desarrollado en Node.js y utiliza el paquete nodemailer con el protocolo SMTP. Para cuentas de Google, la autenticación tradicional (usuario y contraseña) está deprecada por políticas de seguridad, por lo que es de carácter obligatorio implementar Contraseñas de Aplicaciones.

FASE 1: Preparación de la Cuenta Remitente (Google)

1.1 Activación de Verificación en Dos Pasos (2FA)

  1. Inicie sesión en su navegador principal con la cuenta de Gmail desde la cual desea que salgan los correos (ej. congreso@ejemplo.com).
  2. Diríjase al panel de Gestión de cuenta de Google: https://myaccount.google.com/
  3. En el menú de navegación izquierdo, seleccione Seguridad.
  4. Desplácese hasta la sección "Cómo inicias sesión en Google".
  5. Verifique el estado de "Verificación en dos pasos". Si se encuentra inactiva, proceda a activarla siguiendo las instrucciones en pantalla (requerirá validación vía SMS a un dispositivo móvil).

1.2 Generación de App Password (Contraseña de Aplicación)

  1. Con la 2FA activa, acceda directamente al panel de contraseñas de aplicaciones mediante el siguiente enlace:
    👉 https://myaccount.google.com/apppasswords
  2. En el campo de "Nombre de la aplicación", asigne un identificador de sistema, por ejemplo: Servidor Node Congreso.
  3. Haga clic en Crear.
  4. El sistema arrojará un token temporal de 16 caracteres alfabéticos (resaltado en un recuadro amarillo).
  5. Copie esta cadena. (Nota: los espacios mostrados en la interfaz gráfica son meramente visuales, la cadena original no posee espacios y debe usarse de corrido).

1.3 Desbloqueo de Seguridad SMTP (DisplayUnlockCaptcha)

Para evitar que el firewall de Google bloquee las primeras transacciones del servidor bajo el error 535-5.7.8 BadCredentials:

  1. Desde el mismo navegador donde mantiene la sesión iniciada, acceda a:
    👉 https://accounts.google.com/DisplayUnlockCaptcha
  2. Presione el botón Continuar.
  3. Google otorgará una ventana de 10 minutos de gracia para que la nueva aplicación (su sistema backend) pueda establecer el apretón de manos inicial (Handshake) con el servidor SMTP.

FASE 2: Inyección de Credenciales en el Entorno Backend

2.1 Modificación del Archivo de Entorno (.env)

  1. Localice el directorio raíz del módulo de backend: /backend-provisorio.
  2. Ubique y edite el archivo oculto .env (Environment Variables).
  3. Asegúrese de que las variables del bloque SMTP se encuentren configuradas exactamente de la siguiente manera:
# Configuración de Correo Electrónico (Nodemailer - Gmail)
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=su_correo_oficial@gmail.com
SMTP_PASSWORD=lasdieciseisletras
Importante:
  • Reemplace su_correo_oficial@gmail.com por la dirección real.
  • Reemplace lasdieciseisletras por el token de 16 caracteres obtenido en la Fase 1.2, sin comillas y sin espacios.

2.2 Reinicio del Proceso Node.js

Para que el motor de Node.js rehidrate las variables de entorno en el objeto global process.env, el servicio debe ser reiniciado forzosamente.

  1. Abra la terminal donde se está ejecutando el servicio de backend.
  2. Interrumpa el proceso actual utilizando Ctrl + C.
  3. Vuelva a iniciar el orquestador:
npm run dev
# o en entorno de producción: npm run start

FASE 3: Validación Final

  1. Ingrese a la plataforma web (Frontend) y navegue a la interfaz de la credencial digital generada de cualquier usuario de prueba.
  2. Oprima el botón azul de "Enviar por E-Mail".
  3. Revise la consola del servidor backend; si la configuración fue exitosa, visualizará la transcripción en la salida estándar (stdout):
-----------------------------------------
Email enviado a: participante@dominio.com
-----------------------------------------
  1. Adicionalmente, el envío del correo electrónico quedará auditado en la carpeta de Enviados de la cuenta de Gmail configurada.
